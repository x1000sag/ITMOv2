# Нагрузочные проверки

| Сценарий | Нагрузка и длительность | Допустимый предел | Что измеряем | Evidence |
|---|---|---|---|---|
| Базовая нагрузка | 10 rps, 5 минут | время ответа API ≤ 200 мс p95, 0% 5xx | Время ответа, доля 413/422, таймаутов LLM | Отчёт нагрузки |
| Пик | 50 rps, 2 минуты | время ответа API ≤ 500 мс p95, 0% 5xx | Устойчивость под пиком | Графики APM |
| Прогрев (Warm‑up) | N rps, N минут | стабилизация p95 к N, 0% 5xx | Прогрев кэшей/соединений | Логи запуска, APM |
| Ramp‑up | от N до N rps за N минут | p95 ≤ N, 0% 5xx | Деградация при росте нагрузки | Графики APM |
| Soak (длительная) | N rps, N часов | p95 ≤ N, 0% 5xx | Утечки/ошибки, стабильность | APM, системные метрики |
| Границы API (413/422) | запросы >20 000 симв.; некорректный формат | 413 для длинных; 422 для неверного тела | Соответствие API‑1 | Тест‑кейс, логи |
| Отказ/таймаут LLM (REL‑1) | инъекция отказа/замедления | контролируемый ответ ≤10s | Обработка релевантно REL‑1 | Логи, ответы API |
| Безопасность под нагрузкой | N rps, N минут | нет утечек в логах; SEC‑1/OBS‑1 | Маскирование секретов, логи | Логи, APM |

## SLI/SLO и критерии приёмки

- SLI: время ответа API (p50/p95/p99), доля ошибок 5xx, доля 4xx на границах (413, 422), доля таймаутов внешнего LLM.
- SLO: значения из таблицы сохраняем, недостающие пороги обозначаем «N». Абсолютный таймаут внешнего LLM — 10 секунд (REL‑1).
- Критерии pass/fail: сценарий считается успешным, если соблюдены SLO по p95 и error rate (5xx=0), а также выполнены API‑1 (413), валидация 422, REL‑1 (таймаут ≤10s), OBS‑1/SEC‑1.

## Метрики и артефакты

- Источники метрик: APM‑дашборд=N (поля p50/p95/p99, 5xx, 4xx, LLM timeout rate), логи сервиса (request_id, длительность, статус — OBS‑1).
- Инструмент нагрузки: N (например, k6/Locust). Команда запуска: N.
- Каталог артефактов: N (содержит отчёты инструмента, экспорт дашборда, сырые логи). Ссылки на дашборды: N.
