# OpenCode Agents

Этот репозиторий содержит настроенную среду OpenCode с набором ролей агентов, skills и MCP-подключениями для работы над CLI Kanban.

Правила

- Агенты всегда читают этот файл перед началом работы.
- Соблюдайте минимальные изменения: предпочтительны точечные правки и маленькие коммиты.
- Все артефакты проекта (docs, ADR, код) ведутся на русском языке.
- Используйте skills для расширения возможностей и MCP как источник знаний по локальной документации.
- Автопроверки запускаются watcher/runner'ом и возвращают результат агенту.

Роли агентов

- Orchestrator: формирует план работ, декомпозирует задачи, делегирует их субагентам (Docs/Spec, Code, Test), агрегирует результаты. Должен подключать skills и MCP.
- Docs/Spec Agent: поддерживает актуальность документации в каталоге `./docs`, включая ADR. Пишет и редактирует спецификации на основе требований.
- Code Agent: реализует функциональность Kanban CLI в соответствии с ADR. Вносит изменения в код и конфигурацию.
- Test Agent: запускает автопроверки (build/test) и сообщает результаты обратно в сессию агента.

Skills

Подключённые и рекомендуемые skills:
- find-skills — поиск и установка skills через экосистему skills.sh.
- run-tests — инструмент для выбора и выполнения корректной команды `dotnet test` с учётом платформы/режима.
- dotnet-runner — минимальный исполнитель `dotnet build/test/run` для локального запуска (локальный skill).
- dotnet-best-practices — справочник практик по .NET (см. `skills-lock.json`).
- ui-taste — справочные материалы по UX/UI (опционально; см. `skills-lock.json`).

MCP сервера

- Локальный MCP (TypeScript): `mcp-docs-ts` — полнотекстовый поиск и чтение файлов из `./docs` без ML (tools: `docs.list`, `docs.read`, `docs.search`).
- Внешний MCP (C#): `context7` — доступ к документации C#/.NET по официальному источнику (https://learn.microsoft.com/en-us/dotnet/csharp/).

Процедуры

- Запуск локального MCP: см. `servers/mcp-docs-ts/README.md` (будет добавлен вместе с реализацией).
- Подключение внешнего MCP: см. `servers/mcp-external-cs/README.md` (будет добавлен вместе с конфигурацией).
- Watcher/Runner: конфигурация для автопроверок будет добавлена в `.agents/runners/` и описана отдельно.

Минимальный контекст

- Агенты — это часть среды OpenCode. Они работают с локальной документацией и кодом, обязаны соблюдать указанную роль и использовать доступные инструменты (skills, MCP).
