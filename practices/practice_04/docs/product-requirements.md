# Канбан CLI — продуктовые требования

Цель
- Минимальный терминальный планировщик задач для персонального использования.

Объём первой версии (MVP)
- Одна доска, хранящаяся локально в JSON-файле `data/board.json`.
- Колонки на доске (по умолчанию: `ToDo`, `InProgress`, `Done`).
- Карточки с полями: `id`, `title`, `description?`, `tags[]`, `deadline?`, `createdAt`.
- Перемещение карточек только между колонками, без позиционирования внутри колонки.
- Без фильтров и поиска, без множественных досок.

Роли и пользователи
- Один локальный пользователь (однопользовательский сценарий, без синхронизации).

Функции
- Инициализация новой доски: создание файла `data/board.json` с базовыми колонками.
- Управление колонками: просмотр, добавление новой колонки.
- Управление карточками:
  - создание карточки в выбранной колонке;
  - просмотр карточек (всей доски или в рамках колонки);
  - перемещение карточки в другую колонку (без указания позиции);
  - добавление/удаление тегов у карточки;
  - установка/очистка дедлайна у карточки.

Хранение данных
- Один файл: `data/board.json`.
- Запись должна быть атомарной (минимизация риска порчи файла при прерывании записи).
- Схема на высоком уровне:
  - `Board`: `{ name, columns: Column[] }`
  - `Column`: `{ name, cards: Card[] }`
  - `Card`: `{ id, title, description?, tags: string[], deadline?, createdAt }`

Правила и ограничения
- Уникальные имена колонок в пределах одной доски.
- Уникальные идентификаторы карточек (UUID/Guid).
- Теги внутри одной карточки уникальны (без дубликатов).
- Формат дедлайна: `YYYY-MM-DD`; дедлайн опционален.
- Нет позиционирования/сортировки карточек внутри колонки на уровне MVP.
- Нет многопользовательского режима и сетевой синхронизации.
- Удаление карточек/колонок и архив — вне MVP.

CLI и поведение ошибок
- Все операции выполняются через CLI-команды.
- В случае ошибок CLI возвращает ненулевой код выхода и печатает понятное сообщение об ошибке.

Технические заметки
- Язык реализации: C#.
- Версия .NET будет зафиксирована в соответствующем ADR/документации по реализации.
