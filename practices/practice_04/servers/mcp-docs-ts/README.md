MCP Docs TS

Назначение

- Локальный MCP сервер на TypeScript, предоставляющий инструменты для чтения и поиска по каталогу ./docs без ML.
- Инструменты:
  - docs.list — перечисление файлов в каталоге docs
  - docs.read — чтение файла из docs по относительному пути
  - docs.search — полнотекстовый поиск по файлам docs (substring/regex)

Требования

- Node.js 18+

Скрипты

- Установка: npm install
- Сборка: npm run build
- Запуск: npm start

Переменные окружения

- DOCS_ROOT — корневой каталог для чтения (по умолчанию ./docs относительно рабочего каталога)

Примеры

- Успешный сценарий: docs.list при наличии каталога docs возвращает список файлов
- Ошибочный сценарий: docs.read с path вне DOCS_ROOT приведет к читаемой ошибке (защита от выхода за пределы каталога)

Примечания

- Сервер работает через stdio согласно MCP; подключение описывается в AGENTS.md.
