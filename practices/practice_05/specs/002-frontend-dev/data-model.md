# Data Model: Разработка фронтенда (Vue)

**Feature**: 002-frontend-dev  
**Date**: 2026-10-28

## Сущности

### Board (Доска)
Единый источник данных. Содержит имя доски и список колонок.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| name | string | Да | Название доски |
| columns | Column[] | Да | Список колонок |

### Column (Колонка)
Колонка на доске. Имена колонок уникальны в рамках доски.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| name | string | Да | Название колонки |
| cards | Card[] | Да | Список карточек в колонке |

### Card (Карточка)
Карточка задачи. Перемещается между колонками без позиционирования внутри колонки.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| id | string (UUID) | Да | Уникальный идентификатор карточки |
| title | string | Да | Заголовок карточки |
| description | string \| null | Нет | Описание карточки |
| tags | string[] | Да | Список тегов. Теги в карточке уникальны |
| deadline | string \| null | Нет | Дедлайн в формате YYYY-MM-DD |
| createdAt | string (ISO 8601 UTC) | Да | Дата создания в UTC |

## Правила валидации

- Имена колонок должны быть уникальны в рамках доски
- Теги в одной карточке должны быть уникальны
- `id` карточки - валидный UUID
- `deadline` - формат YYYY-MM-DD или null
- `createdAt` - валидная ISO 8601 дата/время в UTC

## Соответствие формату CLI

Формат JSON полностью идентичен формату, используемому CLI:
- Board сериализуется как объект с полями name и columns
- Column как объект с полями name и cards
- Card как объект со всеми полями

TypeScript типы должны быть совместимы с C# моделями для обеспечения 100% совместимости.
