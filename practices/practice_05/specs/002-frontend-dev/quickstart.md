# Quickstart: Разработка фронтенда (Vue)

**Feature**: 002-frontend-dev  
**Date**: 2026-10-28

## Цель

Проверить, что фронтенд корректно работает с данными Kanban-доски и совместим с CLI.

## Предварительные требования

- Node.js и npm установлены
- Существующий файл `data/board.json` с данными (или будет создан)
- .NET SDK для работы CLI (для проверки совместимости)

## Структура проекта после реализации

```
practice_05/
├── kanban-cli/       # Решение .NET
│   ├── src/
│   │   ├── Kanban.Domain/
│   │   ├── Kanban.Infrastructure/
│   │   ├── Kanban.Cli/
│   │   └── Kanban.Api/  # Web API для фронтенда
│   └── tests/
├── frontend/         # Vue 3 + Vite + TypeScript приложение
└── data/
    └── board.json    # Единый файл данных
```

## Быстрая проверка

### 1. Запуск API
```bash
cd kanban-cli
dotnet run --project src/Kanban.Api
# API будет доступен по адресу http://localhost:5000 или http://localhost:5170
```

### 2. Запуск фронтенда
```bash
cd frontend
npm install
npm run dev
# Фронтенд будет доступен по адресу http://localhost:5173
```

### 3. Проверка сценариев

#### Сценарий 1: Просмотр доски
1. Открыть фронтенд в браузере
2. Убедиться, что отображаются все колонки и карточки из `data/board.json`
3. Проверить, что вся информация о карточках отображается (заголовок, описание, теги, дедлайн)

#### Сценарий 2: Создание карточки
1. Нажать кнопку создания карточки
2. Заполнить заголовок, описание, теги, дедлайн
3. Сохранить
4. Убедиться, что карточка появилась в выбранной колонке

#### Сценарий 3: Перемещение карточки
1. Перетащить карточку из одной колонки в другую (drag & drop)
2. Убедиться, что карточка переместилась
3. Проверить, что изменение сохранилось в `data/board.json`

#### Сценарий 4: Редактирование карточки
1. Открыть карточку для редактирования
2. Изменить описание или теги
3. Сохранить
4. Убедиться, что изменения отображаются

#### Сценарий 5: Совместимость с CLI
1. Внести изменения через фронтенд
2. Запустить CLI: `dotnet run --project kanban-cli/src/Kanban.Cli -- <команда>`
3. Убедиться, что CLI корректно читает и отображает изменения из `data/board.json`
4. Сделать изменение через CLI
5. Обновить страницу фронтенда
6. Убедиться, что изменения из CLI отображаются во фронтенде

### 6. Проверка атомарности записи
1. Внести изменения через фронтенд
2. Убедиться, что `data/board.json` обновился корректно
3. Проверить, что файл не поврежден при прерывании (теоретически)

## Критерии успешной проверки

- [ ] Фронтенд отображает существующую доску без потери данных
- [ ] Создание, редактирование, перемещение карточек работают
- [ ] Изменения сохраняются в `data/board.json`
- [ ] CLI корректно читает данные, созданные фронтендом
- [ ] Фронтенд корректно читает данные, созданные CLI
- [ ] Формат данных полностью совместим
- [ ] Фронтенд собирается и запускается без ошибок (`npm run build`, `npm run dev`)
