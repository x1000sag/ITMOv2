## Спецификация
**Пользовательская история (P1)**
- Как пользователь, я хочу создать и редактировать свой профиль, чтобы хранить личную информацию.

### Требования
- Поля: Имя, Фамилия, Email (обязательный), Дата рождения, Профильная фотография URL.
- Валидация email.
- API эндпоинты: POST /profiles, GET /profiles/{id}, PUT /profiles/{id}.
