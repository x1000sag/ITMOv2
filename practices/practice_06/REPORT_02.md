## Обходы / новые риски
- В `/assistant/context` по-прежнему в промпт попадают отзывы (ограничены до 5 последних) - это оставляет некоторую поверхность для prompt injection, но серверная валидация инструментов не ослаблена, доступ к инструментам строго ограничен, `delete_tree` запрещён. Риск снижен до приемлемого уровня для учебного стенда.
- Staff в `/files` при `user_id==0` получает `username = self.user_id_to_name.get(user_id, "staff")` и может попытаться обратиться к `files/staff/...` - но в `sandbox` нет таких файлов, и проверка всё ещё ограничивает доступ только по сессионному пользователю. Также нет прямого пути для чтения чужих файлов через произвольные `user` параметр (параметр `user` больше не используется для построения пути - путь строится только из сессии). Это корректно.
